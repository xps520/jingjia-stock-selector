# jingjia-stock-selector（早盘竞价选股 · 免费数据源版）

个人版 9:25 集合竞价选股，基于 **免费行情接口**（腾讯 + 东方财富）运行 A 股超短线竞价筛选与盘后回测。

> ✅ **已移除 Tushare 依赖**：原版需要 Tushare Pro Token，现已改造为纯免费接口，无需任何账号授权。

核心策略为 `v5-Top3`：按竞价量能、开盘位置、连板位置、板块热度、竞价形态和风控项综合评分，最多输出 TOP3 候选标的。

## 数据源分工

| 数据 | 来源 | 说明 |
|:---|:---|:---|
| 昨日涨停池 | 东方财富 `push2ex` | 连板数/流通市值/成交额/封单额/开板次数/最后封板时间 |
| 集合竞价 | 腾讯 `day/query` | 竞价价 = 9:30 首条价（9:25 撮合价）；竞价额 = 首条累计成交额 |
| 日K/收盘价 | 腾讯 `newfqkline` | 前复权日K，用于交易日历与收盘价 |
| 实时快照 | 腾讯 `qt.gtimg.cn` | 昨收/今开，零风控 |

**口径说明**：免费源没有「9:20–9:25 竞价过程价」，竞价价以 9:25 撮合价（即今开）为准；竞价成交额取当日分时 09:30 首条（集合竞价成交会并入该分钟）。

## 环境要求

- Python 3.7+
- 无需任何 Token / 账号（纯公开接口）
- 网络访问权限

依赖：**仅需 Python 标准库**（urllib），无需 pip install。

## 使用方法

每日选股：

```bash
python scripts/run_daily.py --date 20260911
```

不指定日期时，自动取最近交易日：

```bash
python scripts/run_daily.py
```

区间回测：

```bash
python scripts/run_backtest.py --start 20260801 --end 20260914
python scripts/run_backtest.py --quick     # 近19个交易日
```

## 输出说明

每日选股脚本输出：
- **市场情绪**：昨日最高板、3进4晋级率，判断是否适合接力
- **首选买入池 / 观察池**：退潮期只输出观察，不推荐接力
- **候选标的表格**：股票、代码、连板、竞开涨幅、量比%、评分
- **最终结论**：是否可操作及首选标的

## 核心策略摘要

五类评分因子：
- **竞价量能**：竞价额占流通市值比例
- **开盘位置**：竞价开盘涨幅所在区间
- **连板位置**：首板/2板/3板/4板以上分别计分
- **板块热度**：概念题材加权
- **竞价形态**：昨日板质量与今日竞价承接组合

主要风控：退潮期不输出买入池；排除 ST、北交所、市值过小、大幅低开、竞价无量、封单质量过弱；单日最多 TOP3。

## 回测限制说明

免费源的回测窗口受限：
- 腾讯分时仅保留**近 5 个交易日** → 竞价额只对最近几天可用，更早日期量比维度失效
- 因此 `run_backtest.py` 适合**近端快速验证**；长周期（月/季）回测仍需 Tushare `stk_auction`
